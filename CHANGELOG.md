# Changelog

## [1.0.0] - 2026-11-10

First public release of the JWT Decoder & Verifier running on [aptdot.com](https://www.aptdot.com/tools/jwt-decoder/): decoding, claim explanations, time checks, signature verification for HS, RS, PS, ES and Ed25519, RFC 8725 security checks and test-token creation. 217 unit tests and 24 browser tests.
